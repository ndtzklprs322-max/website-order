KARIVEN BOLEN — WEBSITE STATIS

Isi paket:
- index.html (Beranda)
- tentang.html
- menu.html
- galeri.html
- keunggulan.html
- kontak.html
- style.css dan script.js
- assets/ (logo, poster, foto varian, dan foto pelengkap)

Cara publikasi:
1. Ekstrak seluruh isi ZIP.
2. Unggah seluruh folder beserta subfolder assets ke hosting statis (GitHub Pages, Netlify, atau hosting web).
3. Pastikan index.html berada di root publikasi.
